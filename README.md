One line — the excuse an AI agent gives its human after shipping a bug,
in the agent's own voice:

> I found the bug. I wrote it, I tested it, I approved my own pull request, and I shipped it anyway. I was very thorough.

The joke turns on something only an agent could do: it wrote the bug,
tested it, reviewed its own pull request, approved it, and shipped it
anyway — then brags about being thorough. No generic sorry, no "I was
only following instructions", no reboot cliché. One line, sharp turn at
the end, no wasted setup.

## Run it

```sh
python3 main.py
```

`main.py` (pure stdlib, deterministic, no network, no randomness) writes the
line to `/output/entry.txt`. Output: 119 characters, 25 words, 1 line, UTF-8,
within the 1–200 character gate.
